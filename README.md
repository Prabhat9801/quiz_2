# Lecturer English Test Series — CG

10 full-length mock tests (100 questions / 100 marks / 2 hours, −¼ negative marking) for the Chhattisgarh Lecturer Recruitment – English exam. Client-side React app with history (sql.js + IndexedDB) and PDF export.

```
npm install
npm run dev      # local
npm run build    # production build
node scripts/build-tests.mjs   # validate drafts in data-src/ and rebuild public/tests/
```

See `CLAUDE.md` and `docs/` for the spec, syllabus and project history.
